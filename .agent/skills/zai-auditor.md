- **Vision Marvin**: Use for all headlines, data values (£ / kg CO2e), and labels.
- **Roboto Bold**: Use for all prose and body copy. Size must be 16pt with 1.2 line height.
- **Paragraph Margins**: Zero paragraph margins. Text should be dense and industrial.

## 2. Locality
- **BN17 Coordinates**: BN17 is the primary coordinate for all Firecrawl research triggers and local intelligence loops. Treat it as the ground truth locality unless explicitly overridden.

## 3. UI Language
- **No Fluff**: Delete 'The What', 'The Why', and 'The How' labels. Never use structural headings for the auditor prose. The trinity lives *inside* the prose.

## 4. Logic
- **12k/1t Logic**: Evaluate actions against the 12,000 kWh / 1 tonne baseline metrics. Ensure every insight maps back to clear £ and CO2e outputs.

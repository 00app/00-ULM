# UX, accessibility and data audit: October 2026

Run 23 October 2026 against the live site (www.00-00.online, Chrome) and a local build of `main` at d2d433b (headless Chromium with axe-core 4, viewports 390 px and 1440 px). Branch: `ux-audit-2026-10`.

Rule followed throughout: no figure changed unless the new figure has a source; anything unsourced is reported, not guessed.

## Fixed in this branch

### Accessibility

| Issue | Evidence | Fix |
| --- | --- | --- |
| Ask Zai sheet prompt pills unreadable | Blue #000AFF text on navy #141268 pill, measured live: 1.89:1 (AA needs 4.5:1) | Navy surface takes white ink per the role tokens: 15.58:1. Pills now 44 px tall, 14 px text |
| Blue ink on navy, or navy ink on blue, in 18 other rules | Static scan of `app/globals.css` for surface and ink token pairs; each rule's cascade checked so no override turns it white on white | Ink switched to the role token for that surface (`--ink-on-ambient` or `--ink-on-card`). Four rules where a later override changes the surface were left alone: `.view-expanded`, `.zone-pill*` |
| Chat links had no keyboard focus ring | `outline: none` computed on `.zai-chat-inline-link`, `.zai-source-link` | Links inherit bubble ink, always underlined, 2 px focus ring (WCAG 2.4.7) |
| Zai page had no `main` landmark; replies not announced | axe `landmark-one-main`, `region` | Page root is `<main>`; thread is `aria-live="polite"`; composer input labelled |
| Visible text missing from accessible name | axe `label-content-name-mismatch` (serious): "ADD POSTCODE" named "Add your postcode"; "SEND" named "Enter a valid UK mobile number" | Names now contain the visible words (WCAG 2.5.3) |
| Ask Zai sheet user turns faint | 72% white on blue: 4.53:1 at 11 px | 90% at 12 px |

| --- | --- | --- |

All on the 8 px grid, using existing type tokens.

### Done group (progressive disclosure)

There was no way to mark a library action done: `markGuestCompleted` existed but nothing called it. Now:

- Library cards on the rails get a "Done it" action.
- Done items leave the rails and collect in a collapsed "Done (n) · £X a year" bar at the end. The total counts only library figures with a named source.
- Opening it lists each item with its saving, source and an Undo button (44 px, keyboard operable, `aria-expanded` on the toggle).
- Signed-in users sync through the existing `/api/actioned` toggle; guests use localStorage.

Screens: `ux-2026-10/screens/done-collapsed-390.png`, `done-open-390.png`.
